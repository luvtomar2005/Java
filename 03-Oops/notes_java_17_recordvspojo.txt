Now this consist setter , getter and repetitive code and this is known as 
boiler plate of the code
What if a class only stores data? Why should developers write all this repetitive code?

A record is a special type of class introduced in Java 16 (previewed in Java 14) that is designed to hold immutable data. 
The compiler automatically generates constructors, accessor methods, toString(), equals(), and hashCode(), reducing boilerplate code. 
Records are commonly used for DTOs, API request/response objects, and immutable data models.
